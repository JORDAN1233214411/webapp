# 🌟 Glowing Calculator App

A beautiful, feature-rich calculator application with a stunning blue and green glowing theme. This calculator offers both standard and scientific modes with extensive customization options.

## ✨ Features

### Core Functionality
- **Basic Operations**: Addition, subtraction, multiplication, division, and percentage calculations
- **Scientific Mode**: Advanced mathematical functions including:
  - Trigonometric functions (sin, cos, tan)
  - Square root and power operations
  - Logarithms (log base 10 and natural log)
  - Factorial calculations
  - Mathematical constants (π and e)
  - Reciprocal function (1/x)
  - Sign toggle (+/−)

### Visual Customization
- **Multiple Themes**: 
  - Blue & Green Glow (default)
  - Purple & Cyan Glow
  - Red & Orange Glow
  - Pink & Yellow Glow
- **Adjustable Glow Intensity**: Control the intensity of the glowing effects (0-100%)
- **Brightness Control**: Adjust overall display brightness (50-150%)
- **Font Size Adjustment**: Customize display text size (20-60px)

### Settings
- **Scientific Mode Toggle**: Enable/disable scientific calculator features
- **Decimal Places**: Set precision (2, 3, 4, 5, 6, 10, or all)
- **Button Click Sound**: Optional audio feedback for button presses
- **Reset to Defaults**: Restore all settings to their default values
- **Local Storage**: All settings are automatically saved and persist between sessions

### User Experience
- **Keyboard Support**: Use your keyboard for quick calculations
  - Numbers: 0-9
  - Operations: +, −, ×, ÷, %
  - Calculate: Enter or =
  - Delete: Backspace
  - Clear: Escape
- **Responsive Design**: Works beautifully on desktop and mobile devices
- **Smooth Animations**: Glowing pulse effects and smooth transitions
- **Real-time Display**: Previous value and operator shown during calculations

## 🎮 How to Use

1. **Basic Calculation**:
   - Click numbers to enter values
   - Click an operator (+, −, ×, ÷, %)
   - Enter the next number
   - Press = to calculate

2. **Scientific Mode**:
   - Click the settings gear icon (⚙️)
   - Check "Enable Scientific Mode"
   - Use advanced functions like sin, cos, sqrt, log, etc.
   - Insert constants π and e as needed

3. **Customize**:
   - Click the settings gear icon (⚙️)
   - Adjust theme, glow intensity, brightness
   - Set decimal places for precision
   - Toggle button sounds
   - Adjust font size
   - Click "Reset to Defaults" to restore original settings
